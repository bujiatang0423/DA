# 「四维盾剑策略」完整手册（V2.12 混合量化与可回测版）

> 版本日期：2026-07-16
>
> 策略性质：政策与财报文本因子 + 横截面排名 + 确定性交易规则
>
> 适用市场：A股现货股票与场内ETF，不包含融资融券、期权和自动下单
>
> 参数状态：本版参数均为首轮回测参数，不代表已经验证有效

## 一、版本定位与变更摘要

V2.12保留“四维盾剑”原有的政策、市场、基本面和技术框架，
但改变决策分工：

- LLM只负责政策与财报文本的结构化提取、评分、证据引用和红灯识别；
- 程序负责股票池过滤、横截面排名、仓位计算、买卖触发和组合风控；
- 所有交易动作必须由确定性规则产生，LLM不得直接给出买卖数量；
- 核心策略与波段策略分账管理，不允许持仓期间因盈利而改变策略类型；
- 取消真实观察仓、95%-100%目标仓位、信号稀缺加重仓和ETF强制补位；
- 仓位由单笔风险预算与止损距离反推，不再由“三维票数”直接决定；
- 成本价只用于盈亏核算，不参与最高点回撤和趋势止损计算；
- 新增时点数据契约、LLM审计契约、A股成交约束和完整回测验收标准。

V2.12的目标不是单独追求胜率，而是在控制回撤的前提下提高净期望值。

```text
单笔净期望 = 胜率 × 平均盈利 - 败率 × 平均亏损 - 交易成本
```

## 二、核心理念与决策权限

### 2.1 四维信息架构

| 维度 | 主要内容 | 决策作用 |
| --- | --- | --- |
| 政策维 | 国内外政策、规划、执行和限制 | 政策因子与否决 |
| 财报维 | 营收、利润、现金流和风险事项 | 基本面分与灯号 |
| 强度维 | 相对行业和宽基的20/60日收益 | 横截面竞争力 |
| 交易维 | 趋势、突破回踩、量价和波动率 | 入场、止损和退出 |

### 2.2 决策权限边界

LLM可以：

- 从指定的历史时点材料中提取政策和财报事实；
- 输出结构化评分、红黄绿灯、置信度和证据；
- 在有明确证据时触发政策红灯或财报红灯；
- 标记数据缺失、材料冲突和无法判断。

LLM不可以：

- 直接输出买入、卖出、加仓、减仓或仓位百分比；
- 使用输入材料之外的新闻、记忆或常识补充历史事实；
- 修改量化分数、市场状态、止损价或组合风险预算；
- 因股价已经上涨而事后改变持仓分类；
- 在证据不足时把“未知”解释为“通过”。

确定性引擎负责：

- 股票池与流动性过滤；
- 因子标准化、综合评分和横截面排名；
- 市场状态、总仓位和行业上限；
- 入场状态机、风险仓位、加减仓和退出；
- T+1、涨跌停、停牌、费用、滑点和成交模拟；
- 版本、输入、输出、信号和订单的审计记录。

## 三、不可违反的总纪律

1. 系统永不自动实盘下单，所有真实交易必须人工确认。
2. 任何历史判断只能使用决策时点已经公开的数据。
3. 信号在T日收盘后确认，常规交易最早在T+1执行。
4. 财报红灯、限制性政策红灯和退市风险拥有最高否决权。
5. 不因没有候选而强制持仓，现金和逆回购是正常状态。
6. 不允许亏损加仓，不允许通过加仓重置最高价或放宽止损。
7. 单笔风险由止损距离决定，信号稀缺不得提高单笔风险。
8. 核心仓与波段仓采用不同退出规则，持仓期间不得相互转换。
9. 无法成交时如实记录未成交，不得假设在涨跌停板上成功交易。
10. 未通过样本外回测的参数不得宣传为有效参数或收益承诺。

## 四、时点数据契约

### 4.1 `as_of`原则

每次分析必须设置唯一的`as_of_time`。进入该次决策的数据必须满足：

```text
数据实际公开时间 <= as_of_time
```

不同数据使用以下可用时间：

| 数据 | 回测可用时间 |
| --- | --- |
| 日线行情 | 交易日收盘并完成落库之后 |
| 分钟行情 | 对应分钟结束且数据已可获取之后 |
| 财务报表 | 交易所实际公告时间，不使用报告期作为可用时间 |
| 政策文件 | 官方网站显示的发布时间或首次抓取时间中较晚者 |
| 行业分类 | 当时有效的历史行业分类 |
| 股票名单 | 当日真实上市、未退市的股票集合 |
| LLM因子 | 原始材料均满足时点要求且结构化输出完成之后 |

### 4.2 禁止的未来函数

- 使用当前仍上市的股票名单回测历史；
- 用修订后的财报覆盖当时尚未发布的数据；
- 使用当天收盘价生成信号，又假设按当天收盘价成交；
- 假设一字涨停可以买入或一字跌停可以卖出；
- 用当前行业分类、当前ST状态或当前公司名称回填历史；
- 用当前LLM对历史公司做开放式评价，却不限制其训练知识；
- 根据完整回测结果反复修改参数，再把同一期间当作样本外结果。

### 4.3 数据缺失处理

- 技术行情缺失：当日不生成该股票的新信号；
- 政策材料全部缺失：禁止新建政策驱动仓位；
- 财报关键字段缺失：财报灯号设为黄灯，基本面分上限60分；
- LLM调用失败：禁止使用该次不完整结果开仓；
- 已持仓遇到非价格数据缺失：价格止损继续有效，不因缺失自动卖出；
- 连续20个交易日没有有效政策或财报更新：对应文本因子向中性50分衰减。

## 五、市场环境过滤

### 5.1 市场基准

主基准使用中证全指；若数据源不可用，按顺序降级为：

1. 沪深300与中证500等权组合；
2. 上证指数与深证成指等权组合；
3. 仅有上证指数时，将市场状态置信度降为低，不得进入90%仓位档。

市场宽度定义为：

```text
市场宽度 = 当日收盘价高于自身MA20的可交易A股数量 / 可交易A股总数
```

可交易A股不包含当日停牌、上市不足120日和已退市股票，
但包含当时真实存在的ST股票，以避免幸存者偏差。
ST股票只参与市场宽度计算，不进入候选股票池。

### 5.2 三档市场状态

设宽基指数收盘价为`I`，其20日和60日均线为`MA20_I`、`MA60_I`。

| 状态 | 确定性条件 | 总仓位上限 | 新开波段仓 |
| --- | --- | ---: | --- |
| 强势 | `I > MA60_I`、`MA20_I > MA20_I[5]`、市场宽度≥55% | 70%-90% | 允许 |
| 弱势 | `I < MA60_I`且市场宽度<40% | 0%-30% | 禁止 |
| 中性 | 不满足强势或弱势 | 40%-60% | 仅允许高分信号 |

弱势状态禁止所有新个股仓，包括核心仓和波段仓。
弱势状态只允许降低风险、持有现金，
或在自身趋势合格时配置防守型宽基ETF。

普通状态切换必须连续2个交易日满足新状态条件，防止单日反复切换。
系统性风险覆盖层即时生效，不受2日确认限制。

具体仓位上限由状态内的风险分决定：

- 强势初始上限80%，市场宽度≥65%且指数高于MA20时可提高至90%；
- 强势但市场宽度跌破50%时降至70%；
- 中性初始上限50%，只在市场宽度≥50%时提高至60%；
- 弱势初始上限20%，市场宽度<30%时降至0%；
- 任一数据降级为低置信度时，使用该状态区间的下限。

### 5.3 过热与系统性风险覆盖层

出现以下任一条件时，覆盖普通市场状态：

| 条件 | 动作 |
| --- | --- |
| 宽度>80%且指数20日涨幅>12% | 仓位上限下调15个百分点 |
| 宽基指数单日跌幅>4% | 当日停止新买入，次日按目标上限降仓 |
| 全市场跌停数量>500只 | 停止新买入，只允许风险卖出 |
| 组合当日从开盘回撤≥3% | 当日停止新增风险，盘后复核 |
| 组合周回撤≥6% | 总仓位上限降至40%，至少保持5个交易日 |
| 组合月回撤≥10% | 总仓位上限降至20%，至少保持10个交易日 |

组合回撤基准统一为：日回撤相对当日开盘净资产；
周回撤相对上周最后一个交易日收盘净资产；
月回撤相对上月最后一个交易日收盘净资产。

冷静期结束需要同时满足：宽基指数重新站上MA20、市场宽度≥45%，
并且最近3个交易日没有再次触发同级组合回撤。

## 六、双策略账本

### 6.1 核心策略账本

定义：政策处于执行阶段、基本面质量较高、相对强度稳定，
预期持有60个交易日以上。

准入条件：

- 政策有效分≥60；
- 政策阶段为试点或执行；
- 财报综合分≥70且财报灯号为绿灯；
- 综合分≥70，横截面排名前15%；
- 收盘价高于MA60，60日相对强度分≥60；
- 初始止损距离满足风险要求。

约束：

- 单只市值上限15%；
- 核心策略账本总市值不超过组合总资产的50%；
- 不因短期MACD死叉直接清仓；
- 财报红灯、政策红灯、硬止损和MA60长期失守不可豁免。

### 6.2 波段策略账本

定义：政策或产业催化明确，价格结构确认，预期持有5-20个交易日。

准入条件：

- 政策有效分≥55；
- 财报综合分≥55且不得为红灯；
- 综合分≥72，横截面排名前10%；
- 相对强度分≥65、趋势分≥65；
- 市场状态为强势，或中性状态下综合分≥78；
- 完成“突破—回踩—重新转强”入场状态机。

约束：

- 单只市值上限12%；
- 不享受基本面一票保留；
- 价格止损、时间止损和移动止盈必须执行。

### 6.3 观察名单

观察名单不是真实仓位。
满足部分条件但尚未完成入场确认的股票只记录状态，不实际买入。

观察信号最长保留5个交易日。
到期未确认、市场转弱、出现红灯或综合分跌破65时失效。

### 6.4 分类冻结

股票建仓时必须写入`strategy_book=core`或`strategy_book=swing`。
在该笔持仓全部退出前不得更改分类。原波段仓即使浮盈超过25%，
仍按波段仓移动止盈；若未来符合核心条件，必须先结束原交易，
再按新的核心信号建立新交易。

## 七、候选股票池与硬过滤

股票必须全部满足以下条件才进入横截面评分：

- 非ST、非`*ST`、无已知退市整理状态；
- 上市满120个交易日；
- 最近20个交易日有效行情不少于18日；
- 20日日均成交额不低于5000万元；
- 计划订单金额不超过20日日均成交额的0.2%；
- 最近20日停牌天数不超过2日；
- 当前不是一字涨停或一字跌停；
- 最近一个交易日收盘价不低于2元；
- 未来2个交易日内没有已知的定期报告预约披露日；
- 不存在财报红灯、限制性政策红灯或重大违法退市风险。

以下数据不得作为硬性通过条件：

- 机构目标价；
- 没有龙虎榜机构卖出；
- 单个平台的“大单资金流入”；
- 因数据缺失而推定没有风险。

## 八、LLM结构化因子契约

### 8.1 输入要求

每次LLM输入只能包含：

- `as_of_time`；
- 当时已经公开的官方政策原文或可靠摘要；
- 当时已经公开的海外监管文件、官方规划或公司正式公告；
- 当时已经公告的财务报表与公告；
- 文档来源、发布时间、首次抓取时间和内容哈希；
- 统一的行业周期与季节性解释规则；
- 禁止使用输入之外知识的明确指令。

政策证据按来源分级：

- A级：国务院、部委、地方政府、交易所等官方原文，可以直接计分；
- A级海外证据：海外监管机构、交易所和上市公司正式公告；
- B级：中央媒体或官方机构转载，必须能够追溯到A级原文才可计分；
- C级：商业媒体、自媒体和论坛，只能作为线索，不进入政策分。

历史回放时，应尽量将公司名称替换为稳定标识，
降低模型调用训练记忆的风险。即使做了替换，
历史LLM结果仍标记为“重建因子”，必须再经过前瞻模拟盘验证。

### 8.2 输出结构

LLM必须输出可验证的JSON对象，不得夹带自由文本交易建议：

```json
{
    "as_of_time": "2026-07-16T15:30:00+08:00",
    "security_id": "anonymous-security-id",
    "model_id": "fixed-model-id",
    "prompt_hash": "sha256-of-prompt",
    "input_hash": "sha256-of-input",
    "policy_direction": "supportive",
    "policy_strength": 78,
    "policy_relevance": 85,
    "implementation_stage": "execution",
    "financial_light": "green",
    "financial_text_score": 72,
    "red_flags": [],
    "llm_confidence": 0.82,
    "evidence_confidence": 0.90,
    "data_completeness": 0.90,
    "evidence": [
        {
            "source_id": "document-hash",
            "published_at": "2026-07-01T09:00:00+08:00",
            "quote": "与结论直接相关的原文"
        }
    ]
}
```

枚举值：

- `policy_direction`：`supportive`、`neutral`、`restrictive`、`unknown`；
- `implementation_stage`：`planning`、`pilot`、`execution`、`mature`、`exit`、`unknown`；
- `financial_light`：`green`、`yellow`、`red`、`unknown`。

`model_id`、`prompt_hash`、`input_hash`和`data_completeness`
由程序外层写入并校验，不信任模型自行填写的值。
`evidence_confidence`由程序按来源等级、证据一致性和完整度计算；
`llm_confidence`只用于诊断，在完成校准前不参与交易评分。

`policy_relevance`必须由主营业务、收入构成或正式项目关系证明，
不能只因公司名称、概念标签或市场传闻给高分。

数值字段必须处于0-100或0-1范围。输出无法解析、证据为空、引用不存在、
哈希不匹配或时间越界时，该次结果无效，不得用于新开仓。

### 8.3 LLM可触发的红灯

LLM只能在材料中存在直接证据时标记红灯：

- 官方政策由支持转为明确限制、暂停或清退；
- 财务造假、重大违法、退市风险警示；
- 非标审计意见且涉及持续经营或重大错报；
- 最近季度营收同比下滑超过30%，且无法由明确季节性解释；
- 扣非净利润由正转负，且不属于已定义的周期行业豁免；
- 经营现金流连续两个季度为负，同时应收或存货占营收比例连续上升；
- 核心产品被正式禁用、召回或确认失去主要商业资格。

红灯必须至少附一条原始证据。模型只有怀疑但没有直接证据时，
只能标记黄灯。

## 九、五因子横截面评分

所有因子统一为0-100分。P和F是基于材料的结构化绝对分，
R和V是当日合格股票池中的横截面百分位分，T是确定性规则分。
综合分S用于当日横截面排名。

### 9.1 政策有效分P

程序先计算政策原始分：

```text
policy_raw_score =
50 + (policy_strength - 50) × policy_relevance / 100
```

再根据政策阶段设置半衰期`H`：

| 阶段 | `H`（自然日） | 阶段系数 |
| --- | ---: | ---: |
| 规划 | 20 | 0.60 |
| 试点 | 40 | 0.80 |
| 执行 | 60 | 1.00 |
| 成熟 | 30 | 0.70 |
| 退出或限制 | 立即红灯 | 0 |

政策随时间向中性50分衰减：

```text
P_decay = 50 + (policy_raw_score - 50) × exp(-政策年龄 / H)
P = 50 + (P_decay - 50) × 阶段系数 × evidence_confidence × data_completeness
```

多份支持性政策同时存在时，
按证据等级、置信度和时间衰减权重计算加权平均，
不得只选择最高分。限制性政策优先覆盖支持性政策。

### 9.2 财报综合分F

财报综合分由数值分和LLM文本分组成：

```text
F = 70% × 财报数值分 + 30% × financial_text_score
```

财报数值分由以下项目在同行业内做百分位排名：

| 项目 | 权重 |
| --- | ---: |
| 营收同比及趋势 | 20% |
| 扣非净利润同比及趋势 | 20% |
| 经营现金流/净利润 | 20% |
| 毛利率或净利率趋势 | 15% |
| ROE或投入资本回报趋势 | 10% |
| 应收与存货占营收比例趋势 | 10% |
| 有息负债与流动性风险 | 5% |

连续数值指标在每个交易日、每个行业内按1%和99%分位缩尾，
再计算百分位，避免极端值支配评分。

周期股、金融股、未盈利成长股和强季节性行业使用以下替代模板，
不得直接套用普通工业企业模板：

- 周期股：毛利率25%、经营现金流25%、负债15%、存货15%、产品价格20%；
- 金融股：ROE 20%、盈利差20%、资产质量20%、拨备或偿付能力20%、
  资本充足20%；
- 未盈利成长股：营收25%、毛利率20%、研发20%、现金消耗15%、
  现金支撑期20%；
- 强季节性行业：同比25%、TTM利润20%、TTM现金流25%、库存15%、负债15%。

金融股的“盈利差”按行业使用净息差或承保利润率，
资产质量使用不良率或同类风险指标。
缺少对应模板所需的两个以上关键字段时，不建立新仓，
且不得临时改用普通模板。

财报黄灯将F上限限制为65分；财报红灯直接否决，不再计算综合分。

### 9.3 相对强度分R

```text
RS20 = 个股20日收益 - 所属行业指数20日收益
RS60 = 个股60日收益 - 宽基指数60日收益
R = 50% × percentile(RS20) + 50% × percentile(RS60)
```

行业指数缺失时，使用宽基指数替代，并把R乘以0.9的数据置信度系数。

### 9.4 趋势结构分T

趋势结构包含四个等权子项：

- 收盘价高于MA20；
- 收盘价高于MA60；
- `MA20[t] > MA20[t-5]`；
- 收盘价突破前20日最高价，或突破后回踩仍守住MA20。

每满足一项得25分。若`(close - MA20) / ATR14 > 2.5`，
视为过度延伸，`T = max(0, T - 20)`，并禁止追高。

MACD、KDJ和布林带只作为诊断字段，不再作为独立票数重复计分。

### 9.5 量价与流动性分V

```text
V = 50% × 突破日量能分
  + 30% × OBV二十日斜率分
  + 20% × 日均成交额分
```

量能分以成交量相对20日均量的比例排名。
比例超过2.5倍时按过热处理，不继续加分。

### 9.6 综合分S

```text
S = 20% × P + 20% × F + 25% × R + 20% × T + 15% × V
```

S主要用于同一交易日横截面排名。
只有在评分公式、行业分类和数据版本均未变化时，
才允许在最多5个交易日内比较S的变化；
更长时间使用横截面排名变化。

## 十、入场状态机

### 10.1 候选状态

```text
未入选 → 已入选 → 突破 → 回踩 → 转强 → 待执行 → 已持仓
```

任一步出现红灯、市场转弱或评分跌破对应阈值，状态回到未入选。

### 10.2 突破日T0

突破日必须同时满足：

- `close[t] > max(high[t-20:t-1])`；
- `close[t] > MA60[t]`；
- `MA20[t] > MA20[t-5]`；
- `1.2 ≤ volume[t] / MAVOL20[t] ≤ 2.5`；
- `close[t] - MA20[t] ≤ 2 × ATR14[t]`；
- R、T、S满足对应策略账本门槛。

### 10.3 回踩观察T1-T5

突破后1-5个交易日内必须出现有效回踩：

- 没有收盘跌破MA20；
- 没有跌破突破日前最近结构低点；
- 至少一个交易日成交量低于MAVOL20的80%；
- 综合分相对突破日T0没有下降超过8分；
- 市场状态没有转为弱势。

超过5个交易日仍未回踩确认，信号失效，不追高买入。

### 10.4 重新转强日

回踩后首次同时满足以下条件视为重新转强：

- 收盘价高于前一交易日最高价；
- 收盘价高于开盘价；
- 成交量高于前一交易日，但不超过MAVOL20的2倍；
- 收盘价仍高于MA20和原突破位；
- S、R、T仍满足建仓阈值。

信号在当日收盘后生成，计划在下一交易日执行。

### 10.5 取消买入

出现以下任一条件时取消待执行订单：

- 下一交易日开盘价较信号日收盘价高开超过3%；
- 开盘即一字涨停或无法在允许滑点内成交；
- 市场状态在执行前转为弱势；
- 出现政策或财报红灯；
- 最新数据导致S跌破建仓阈值；
- 预计成交后突破个股、行业、账本或组合风险上限。

## 十一、止损与风险仓位

### 11.1 ATR与结构止损

ATR使用14日真实波幅均值。候选结构止损为：

```text
结构止损 = 回踩阶段最低价 - 0.2 × ATR14
噪声止损 = 计划买入价 - 1.2 × ATR14
初始止损 = min(结构止损, 噪声止损)
止损距离 = 计划买入价 - 初始止损
```

若止损距离超过2.5倍ATR，放弃交易；不得通过扩大仓位补偿过宽止损。

### 11.2 单笔风险预算

```text
单笔风险预算 = 组合净资产 × 0.5%
理论股数 = 单笔风险预算 / 止损距离
```

理论股数向下取整到100股，并同时受以下上限约束：

- 核心仓单只市值≤净资产15%；
- 波段仓单只市值≤净资产12%；
- 单笔订单金额≤20日日均成交额0.2%；
- 成交后组合总风险敞口≤净资产3%；
- 成交后不得突破市场状态总仓位上限。

向下取整后订单金额不足5000元时不交易。
对于15万元账户，不因资金小而豁免流动性要求。

### 11.3 组合风险敞口

```text
单仓风险 = max(0, 当前价 - 有效止损价) × 持仓数量
组合风险敞口 = 所有单仓风险之和 / 组合净资产
```

移动止损提高后，释放的风险预算可以用于新信号。
止损不得向下移动，因此风险预算不会因主观判断被重新放大。
止损已经触发但尚未成交的仓位标记为`pending_exit`。
在完成退出前禁止新增风险。
跳空导致组合风险超过3%时，优先退出最低S持仓，不追溯修改历史仓位。

## 十二、组合构建与相关性约束

| 约束 | 上限 |
| --- | ---: |
| 总股票数量 | 6只 |
| 单一申万一级行业 | 25% |
| 同一主题或高度相关产业链 | 30% |
| 核心策略账本 | 50% |
| 单只宽基ETF | 15% |
| 组合风险敞口 | 3% |

没有最低持仓数量。
没有合格信号时可以100%持有现金、场内货币基金或逆回购。

宽基ETF只有在自身趋势与市场状态允许时才可配置，
不承担“补满目标仓位”的职责。宽基ETF不计入单一行业权重，
但计入总仓位和市场Beta暴露。

同一行业候选超过上限时，依次选择S更高、流动性更好、
与现有持仓相关性更低的股票。

主题归属使用固定且有版本号的主题映射。
任意两只股票最近60日收益相关系数高于0.75时，
视为高度相关并共同计入30%主题上限；
历史不足60日时按同一行业处理。

## 十三、加仓、减仓与成本核算

### 13.1 加仓规则

加仓必须全部满足：

- 当前持仓浮盈至少达到1R；
- 股价形成新的有效突破和回踩确认；
- S不低于首次建仓时的分数；
- 加仓后个股市值、行业权重和总仓位不超限；
- 提高有效止损后，组合总风险不高于加仓前；
- 同一笔交易最多加仓一次，加仓数量不超过首次买入数量的50%。

禁止在浮亏状态、跌破初始止损后或仅因成本变低而加仓。

### 13.2 正确的移动加权平均成本

```text
新平均成本 =
（原持仓数量 × 原平均成本 + 新增数量 × 买入价 + 买入费用）
/（原持仓数量 + 新增数量）
```

减仓时剩余仓位平均成本不变；卖出费用计入已实现盈亏。
成本价只用于盈亏核算，不改变：

- 历史最高价；
- 最高点回撤；
- MA20、MA60或ATR移动止损；
- 原始交易的1R定义。

### 13.3 最高价与回撤

```text
最高点回撤 = (建仓后最高可用价格 - 当前价格) / 建仓后最高可用价格
```

加仓和减仓均不重置最高价。日线策略默认使用最高收盘价；
盘中紧急风控另行使用盘中最高价。两种口径必须分别保存，不得混用。

## 十四、卖出体系

### 14.1 通用优先级

多条规则同时触发时按以下顺序执行：

1. 财报红灯、限制性政策红灯、退市或重大违法风险；
2. 初始硬止损或有效移动止损；
3. 市场及组合风险降仓；
4. 策略账本退出规则；
5. 横截面排名衰减与动态替换；
6. 主观复核只能减少风险，不能否定第一至第三优先级。

### 14.2 波段策略退出

| 触发条件 | 动作 |
| --- | --- |
| 价格触及初始止损 | 首个可交易时点全部退出 |
| 持仓5日且最大浮盈<0.5R，同时R<50 | 时间止损，全部退出 |
| 浮盈达到1.5R | 止损提高至含费用保本价与原止损中的较高者 |
| 浮盈达到2R | 减持三分之一，只执行一次 |
| 2R之后收盘跌破移动止损 | 剩余仓位全部退出 |
| S<55连续2日或横截面跌出前40% | 全部退出 |
| 财报或政策红灯 | 首个可交易时点全部退出 |

波段仓移动止损：

```text
移动止损 = max(MA20, 建仓后最高收盘价 - 2.5 × ATR14)
```

有效止损只能持平或上移，不能因ATR扩大或均线下跌而下移。

### 14.3 核心策略退出

| 触发条件 | 动作 |
| --- | --- |
| 财报或政策红灯 | 首个可交易时点全部退出 |
| 价格触及初始硬止损 | 全部退出，不享受基本面豁免 |
| 收盘跌破MA20且S<65连续2日 | 减持一半，只执行一次 |
| 收盘跌破MA60连续2日 | 全部退出 |
| R<40且S<55连续5日 | 全部退出 |
| 浮盈达到3R后跌破核心移动止损 | 全部退出 |

核心移动止损：

```text
核心移动止损 = max(MA60, 建仓后最高收盘价 - 3 × ATR14)
```

核心仓可以忽略单独的MACD死叉、KDJ高位和单日缩量，
但不能豁免硬止损、MA60退出和红灯。

### 14.4 跳空、跌停和T+1

- 买入当日触发止损但因T+1不能卖出：记录风险事件，
  次日首个可交易时点卖出；
- 次日开盘低于止损价：按首个实际可成交价格卖出，
  不假设成交在止损价；
- 一字跌停无法成交：每日保留卖出委托，直到首次可成交；
- 停牌期间不假设成交，复牌后按实际可交易状态处理；
- 不同板块涨跌幅限制必须按当时有效的交易规则判断。

### 14.5 动态替换

新候选不得仅因为“看起来更好”而替换持仓。
只有同时满足以下条件才允许替换：

- 现有持仓S低于60或已跌出横截面前40%；
- 新候选S至少高10分且差值连续3个交易日成立；
- 现有持仓没有触发更高优先级退出时，按普通退出价格执行；
- 替换后的预期风险、行业集中度和交易成本均合规。

不采用全仓瞬时切换。先退出旧仓，释放的现金和风险预算，
在下一次有效入场信号中使用。

## 十五、LLM与数据失败降级

| 异常 | 新开仓 | 已持仓 |
| --- | --- | --- |
| LLM输出无法解析 | 禁止 | 价格规则继续执行 |
| 政策源全部失败 | 禁止所有新个股仓 | 旧分沿用5日后衰减 |
| 财报字段缺失 | 缺失黄灯，F上限60 | 价格规则优先 |
| 行业指数缺失 | R乘以0.9 | 继续持有，禁止因缺失直接加仓 |
| 宽基或市场宽度缺失 | 使用市场仓位区间下限 | 禁止新增风险 |
| 行情缺失或日期不一致 | 禁止 | 不生成虚假成交，等待有效行情 |

普通风险黄灯时F上限65；因关键字段缺失触发的数据缺失黄灯时F上限60。

任何降级都必须记录缺失字段、替代数据、受影响因子和最终置信度。

## 十六、执行与交易成本

### 16.1 默认成交模型

- T日收盘生成信号，默认按T+1首个可交易开盘价加滑点模拟成交；
- 使用VWAP属于另一成交模型，必须作为单独策略版本预先固定，
  不得回测后择优；
- 买入开盘价高于信号日收盘价3%以上时取消；
- 常规滑点基准为单边0.10%，压力测试使用0.30%；
- 佣金、最低佣金、印花税和过户费使用当时实际费率；
- 买入数量向下取整到100股，卖出允许处理不足100股的尾仓；
- 订单金额和成交量冲击必须满足流动性过滤。

### 16.2 无成交原则

以下情况回测必须记为未成交：

- 一字涨停买入；
- 一字跌停卖出；
- 停牌；
- 当日成交量不足以支持设定的订单参与率；
- 价格超出允许滑点；
- 交易规则禁止该笔操作。

不得用当天最高价、最低价判断“理论上碰到过”就假设成交。

日线硬止损成交模型固定为：

```text
若 open <= stop：卖出价 = open × (1 - 卖出滑点)
若 open > stop 且 low <= stop：卖出价 = stop × (1 - 卖出滑点)
其他情况：当日未触发止损
```

若当日处于跌停封单、停牌或无足够成交量，
上述理论价格作废，记录为未成交。

## 十七、日常运行流程

### 17.1 每日盘后

1. 固化当日可交易股票名单、行情和市场宽度；
2. 更新政策与财报的时点数据；
3. 对新增文本运行LLM结构化提取并验证证据；
4. 计算P、F、R、T、V和综合分S；
5. 更新候选状态机和持仓有效止损；
6. 生成次日待执行清单；
7. 保存数据版本、策略版本、提示词哈希和原因码。

### 17.2 次日盘前与执行时点

1. 检查停牌、ST、公告、涨跌停和隔夜风险；
2. 重新检查市场状态与组合风险上限；
3. 取消不满足条件的买入订单；
4. 风险卖出优先于新买入；
5. 记录实际或模拟成交价格、费用、滑点和未成交原因。

### 17.3 周度与月度审视

周度检查：

- 市场状态切换频率；
- 因子缺失率与LLM失败率；
- 行业和主题集中度；
- 组合风险敞口和冷静期状态；
- 未成交及滑点异常。

月度检查：

- 核心策略与波段策略分别统计；
- 五因子贡献与因子衰减；
- 红黄绿灯命中及误判；
- 实际成交相对模型成交的偏差；
- 参数只记录观察结果，不在月中临时修改。

## 十八、完整回测规范

### 18.1 四组对照实验

| 组别 | 使用因子 | 目的 |
| --- | --- | --- |
| A | R + T + V | 技术与相对强度基线 |
| B | F + R + T + V | 检验财报增量 |
| C | P + R + T + V | 检验政策LLM增量 |
| D | P + F + R + T + V | 检验完整混合策略 |

四组必须使用相同股票池、市场过滤、成交模型、费用和风险预算。

### 18.2 样本划分

采用滚动前推，而不是在全历史上一次性优化：

```text
前3年：参数开发
后1年：完全样本外验证
窗口向前滚动1年并重复
```

最新12个月在首次定参数前锁定为最终保留样本，
不允许根据该期间结果修改参数。

### 18.3 必须报告的指标

- 年化收益率；
- 最大回撤及恢复时间；
- Calmar比率；
- 净利润因子；
- 净胜率；
- 平均盈利/平均亏损；
- 每笔交易净期望值和R倍数分布；
- 年化换手率、交易成本和滑点；
- 平均仓位、最大行业暴露和组合风险敞口；
- 未成交率、涨跌停受阻次数；
- 强势、中性、弱势市场的分组表现；
- 核心账本与波段账本的独立表现。

### 18.4 首轮验收门槛

参数进入模拟盘前至少满足：

- 样本外已平仓交易不少于200笔；
- 样本外净利润因子不低于1.30；
- 样本外每笔净期望值大于0；
- 最大回撤不高于25%；
- 参数在相邻范围内仍保持正期望，不依赖单一尖峰参数；
- D组相对A组至少改善利润因子、Calmar、胜率、最大回撤中的两项；
- D组不得以平均亏损显著扩大换取更高胜率；
- 不同年份和市场状态下不存在由单一年份贡献全部利润的情况。

上述门槛是研究门槛，不是收益承诺。
任何一项不满足都应继续保留在研究或模拟阶段。

### 18.5 LLM因子的额外验证

- 固定模型标识、提示词、温度、输出结构和超时配置；
- 归档每次输入、输出、证据、模型版本和内容哈希；
- 对同一输入重复运行，统计评分一致性；
- 抽样人工核验证据是否支持结论；
- 单独比较有无LLM文本分的结果；
- 历史LLM结果标记为“重建”，从V2.12启用日起开展前瞻模拟验证；
- 如果LLM因子没有稳定增量，权重降为0，而不是通过继续调参保留。

## 十九、参数治理与版本控制

V2.12启用后，任何参数修改必须：

1. 形成新的策略小版本，例如V2.12.1；
2. 记录修改原因、假设和预期影响；
3. 在保留样本之外完成参数研究；
4. 重新运行全部对照组和样本外验证；
5. 保存旧版本结果，不覆盖历史建议；
6. 模拟盘至少运行20个交易日后再讨论进入人工实盘辅助。

禁止因为最近几笔亏损临时修改止损、权重、市场阈值或评分门槛。

## 二十、策略边界与已知局限

- 政策因子存在发布时间不准确、执行滞后和市场提前交易的问题；
- LLM无法彻底消除训练知识带来的历史泄漏，
  因此历史结果必须由前瞻测试确认；
- 横截面排名在行业集中行情中可能放大风格暴露；
- ATR和均线止损无法消除连续跌停、停牌和隔夜跳空风险；
- 财报数据低频，不能作为短线卖点的唯一依据；
- 15万元账户受最低佣金和100股交易单位影响，
  理论风险与实际风险会有偏差；
- 回测结果不能代表未来，任何收益目标都不是承诺；
- 本系统只生成建议，不实施自动交易。

## 二十一、V2.12执行摘要

### 新开仓必须同时满足

- 时点数据完整且没有红灯；
- 市场状态允许；
- 股票通过硬过滤；
- P、F、R、T、V和S达到对应账本门槛；
- 完成突破、回踩、重新转强状态机；
- 通过0.5%单笔风险预算计算后仍有可交易数量；
- 不突破个股、行业、账本、总仓位和3%组合风险上限；
- T+1实际可成交。

### 持仓期间必须执行

- 止损只能上移，不能下移；
- 不亏损加仓，不重置最高价；
- 核心与波段分类冻结；
- 红灯、硬止损和组合降仓优先；
- 无法成交必须记录，不假设成交；
- 所有结论保留数据、证据、评分和原因码。

### 五句纪律

1. 没有可验证的证据，就没有政策和财报优势。
2. 没有样本外增量，就不保留复杂因子。
3. 仓位由风险决定，不由故事、稀缺或信心决定。
4. 现金不是踏空，是未发现正期望机会时的正确仓位。
5. LLM负责读懂材料，规则负责管住交易，人负责最终确认。
